# OrderBoard Beta

Минимальный прототип единой платформы «магазин ↔ поставщик».

Сценарий:
1. Продавец входит под `seller / 1234`.
2. После смены указывает количество товаров на завтра.
3. Нажимает «Смена закончена — отправить поставщику».
4. Поставщик входит под `supplier / 1234` и сразу видит заявку и уведомление.
5. Поставщик нажимает «Подтвердить поставку на завтра».
6. Магазин видит подтверждение на общей доске.

## Запуск
Требуется Java 21+.

```bash
javac --add-modules jdk.httpserver -d out src/main/java/Main.java
java --add-modules jdk.httpserver -cp out Main
```

Открыть: http://localhost:18080

## Важно
Это учебная beta: данные хранятся в памяти и пропадут после перезапуска. В следующей версии нужно подключить PostgreSQL, нормальную авторизацию, пользователей/магазины/поставщиков, историю заказов и реальные push/email/Telegram уведомления.
